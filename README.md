# Deep Vision in Classification Tasks

Este repositorio contiene el desarrollo del proyecto de programación de la asignatura **Redes Neuronales y Deep Learning (07MIAR)**, cuyo objetivo es abordar un problema de clasificación de imágenes mediante técnicas de aprendizaje profundo (*Deep Learning*), utilizando redes neuronales convolucionales (CNN).

El proyecto contempla la implementación, entrenamiento y comparación de dos estrategias: el diseño de una CNN desde cero (*From Scratch*) y el uso de arquitecturas preentrenadas mediante *Transfer Learning* y *Fine-Tuning*. Se aplican diferentes técnicas de regularización y optimización para evaluar el rendimiento de los modelos y determinar cuál ofrece los mejores resultados en la tarea de clasificación.
